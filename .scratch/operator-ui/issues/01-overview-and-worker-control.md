# 01: Обзор и управление обработчиком

**What to build:** Оператор открывает локальную панель, видит состояние приложения, источников и брокера и может запустить, штатно остановить или перезапустить обработчик.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Панель запускается на том же компьютере, что и обработчик, и доступна только локально. Запуск и остановка требуют действующей локальной сессии оператора. Недоверенный браузерный источник не может выполнить команду через эту сессию.
- [x] На обзоре видны режим, состояние обработчика, счёт, разрешённые контракты, состояние источников, время последней сверки, позиция, состояние защиты и понятная причина блокировки, если она есть.
- [x] Обзор обновляется автоматически. При отсутствии или потере свежего подтверждения позиция и защита отмечены как неизвестные. Последнее подтверждённое состояние и время сверки остаются различимы. «Позиции нет» появляется после успешной сверки.
- [x] Запуск использует выбранную конфигурацию и каталог данных. Повторный запрос запуска или запуск из второй вкладки не создаёт второй обработчик для того же каталога.
- [x] Панель показывает переходные состояния запуска и остановки, а также результат команды. Штатная остановка оставляет очередь доступной для восстановления и сохраняет уже установленную на платформе защиту.
- [x] Закрытие вкладки оставляет обработку запущенной. После сбоя обработчика панель остаётся доступной, показывает причину и позволяет явно перезапустить обработку с тем же каталогом данных.
- [x] Ответы панели и журнал команд не раскрывают ключи, содержимое файлов сессий и секреты из ошибок подключения.
- [x] По инструкции из корня проекта можно запустить панель, открыть локальный адрес и выполнить цикл запуска и остановки. Автоматическая проверка с управляемым обработчиком покрывает локальную сессию, повторный запуск, сбой, восстановление и устаревшую сверку.

## Результаты проверки

- Windows, Python 3.11.9. Прошёл полный прогон из 151 теста и
  `mypy --strict news_futures tests`. Автономный контрольный сценарий
  по-прежнему проходит в изолированном Python без сторонних библиотек.
- Проверки с управляемым процессом покрывают локальную сессию, команды из
  двух вкладок, сбой и восстановление, свежесть сверки и очистку ответов
  и журнала от секретов. Рабочий подпроцесс отдельно проверен на запуск
  с выбранной конфигурацией и отказ при занятом каталоге.
- В Chromium с управляемым обработчиком пройдены запуск, уход со страницы,
  перезапуск и остановка. После остановки текущая позиция неизвестна, последнее
  подтверждение видно отдельно. При ширине 375 px нет горизонтальной прокрутки.
- Штатное завершение очереди и сохранение SL/TP проверены с управляемыми
  транспортом и брокером.

**Не проверено:** сквозной запуск панели с живыми Telegram, OpenRouter и
Т‑Банком, а также сохранение фактически выставленных SL/TP при остановке.
