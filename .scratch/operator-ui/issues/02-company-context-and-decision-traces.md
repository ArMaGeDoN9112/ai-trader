# 02: Тикеры и трассы решений

**What to build:** Оператор ищет компанию по тикеру акции или фьючерса, открывает связанное новостное событие и прослеживает решение от исходной публикации до результата.

**Blocked by:** 01 — Обзор и управление обработчиком.

**Status:** resolved

- [x] Поиск по тикеру акции или фьючерса открывает карточку компании. Новостной контекст остаётся общим для компании, а позиции, заявки и решения можно фильтровать по серии фьючерса, включая прошлые серии.
- [x] В карточке видны события, связанные публикации, редакции и ссылки на первоисточники. Публикация с несколькими сохранёнными привязками доступна из каждой затронутой компании.
- [x] Косвенная или неуверенная привязка помечена «Гипотеза». Результат проверки аналитиком виден, когда он сохранён.
- [x] В «Решениях» и блоке последних решений на обзоре видны только публикации с сохранённой привязкой. Пропуски, блокировки и отказы доступны, даже если сделки не было. Список фильтруется по компании, контракту, периоду и результату.
- [x] Трасса показывает фактически пройденные шаги в порядке выполнения: исходную публикацию, привязки Jev, сопоставление события, предложение аналитика, ответ критика, пересмотр при наличии, проверку риска и действия исполнителя. Для каждого доступного шага видны результат и время.
- [x] Из шага раскрываются сохранённый вход, полный доступный ответ и ссылки на исходные материалы. Ошибки, пропуски и незавершённые шаги показаны там, где возникли. Отсутствующие детали не подменяются выдуманными ответами.
- [x] Список решений обновляется автоматически, а открытая трасса сохраняет положение прокрутки и раскрытые шаги. Публикации и ответы моделей отображаются как данные. Ключи и служебное содержимое сессий не попадают в браузер.
- [x] Автоматическая проверка проходит от поиска по тикеру до трассы отклонённого решения. Она покрывает публикацию без привязки, прямую связь и гипотезу для разных компаний, прежнюю серию контракта и обновление открытой трассы.

## Результаты проверки

- Итоговый прогон на Windows с Python 3.11 и Chromium прошёл, 155 тестов.
  Проверка `mypy --strict news_futures tests` прошла.
- Сквозной тест проходит от поиска по тикеру акции и прошлой серии фьючерса
  до отклонённой трассы. Он проверяет прямую привязку, гипотезу с выводом
  аналитика, исключение непривязанной публикации, фильтры, первоисточник,
  безопасный вывод текста и обновление раскрытой трассы. При ширине 375 px
  горизонтальной прокрутки нет.
- Тесты с управляемыми моделями и брокером проверяют отказ проверки риска,
  блокировку до её вызова и порядок проверки и заявок для входа и новостного
  выхода. Отдельно проверены заявки серии, убранной из разрешённых контрактов.
- Проверены атомарная замена файла после параллельного чтения в Windows и
  сохранение подтверждённого результата при недоступности файла аудита риска.
- Для архивной серии без сохранённого тикера доступен UID. Если время шага
  отсутствует, панель показывает время сохранения файла отдельно, когда оно
  доступно. Полные ответы показаны в объёме сохранённых данных.

## Ревью

- Требования. В карточку включены связанные через событие материалы.
  Для редакции без привязки доступен исходник. Трасса показывает
  незавершённую проверку риска до действий брокера и сохранённый код отказа.
- Стандарты. Устранены конфликт чтения с записью в Windows и утечка
  полей авторизации в сохранённом тексте. Ошибка файла аудита отделена
  от результата исполнения.

## Не проверено

- Живые Telegram, OpenRouter и Т‑Банк. Брокерские операции проверялись
  на управляемом брокере.
- Другие браузеры и производительность на большом архиве.
