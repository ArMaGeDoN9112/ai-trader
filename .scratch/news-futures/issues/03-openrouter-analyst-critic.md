# 03: Аналитик и критик работают через OpenRouter

**What to build:** Контрольная публикация и заданный контекст получают торговое предложение от аналитика через OpenRouter и решение критика. Оператор может сменить модель каждой роли настройкой, а по журналу восстановить, какие модели приняли решение.

**Blocked by:** 01 — Контрольная публикация проходит всю цепочку локально.

**Status:** resolved

- [x] Модели аналитика и критика задаются независимо через настройки OpenRouter без изменения кода; ключи остаются локальными.
- [x] Каждый цикл использует снимок настроек на весь анализ, критику и пересмотр. Смена настроек применяется со следующего цикла.
- [x] Предложение и ответ критика проходят проверку структуры и смысловых ограничений. Невалидный, оборванный или неподдерживаемый ответ не допускается к исполнению.
- [x] Используется только совместимый с обязательной схемой endpoint; ошибка не обходится ослаблением схемы или незаявленной заменой модели.
- [x] Вход и новостное закрытие требуют согласия аналитика и критика. После возражения допускаются один пересмотр и одна повторная проверка изменённого предложения.
- [x] Неустранённые существенные возражения отклоняют предложение в этом запуске. Исполнитель не получает непроверенный пересмотренный вариант.
- [x] Текст публикации обрабатывается как недоверенные данные и не может менять права исполнения, настройки или лимиты риска.
- [x] Сохраняются запрошенная и фактическая модели, доступные сведения о провайдере, версия настроек, результаты, ошибки, задержка и доступный расход.
- [x] Сквозные проверки покрывают одобрение, отказ, успешный пересмотр, повторный отказ, невалидный ответ, сетевую ошибку и смену настроек между циклами.
- [x] Работа с реальной выбранной моделью подтверждается при настроенном доступе; эта проверка не выдаётся за проверку качества торговой стратегии.

## Answer

Реализован только срез 03, 2026-11-06. Предусловие 01 подтверждено его
документированной приёмкой и повторным изолированным прогоном `-I -S`.
Команда `analyze` запускает StateGraph: аналитик → критик → при возражении
один пересмотр → одна повторная критика. Стандартный `run` из 01 не изменён.
Инструкция: [OpenRouter](../../../docs/openrouter.md).

| Критерий | Свидетельство |
| --- | --- |
| Независимые модели, локальный ключ | JSON для двух ролей; тест production client проверяет OpenRouter key/base URL и игнорирование OpenAI env. |
| Снимок настроек | SHA-256 снимка; тест меняет файл во время первого запроса, весь пересмотр использует прежние модели, следующий цикл — новые. |
| Структура и смысл | Pydantic strict/extra-forbid, конечные положительные цены, стороны уровней, ссылки, действия по позиции; критика проверяет точный программный ID и непротиворечивое согласие. |
| Совместимый endpoint | JSON Schema strict + require_parameters; HTTP 400, обрыв, refusal и подмена модели дают отказ без fallback. |
| Бюджет согласования | Тесты входа и полного закрытия; не более четырёх модельных запросов; повторный отказ/ошибка не дают approved_proposal. |
| Недоверенная публикация | HumanMessage с данными, системные правила отдельно, нет tools и брокера; попытка выбрать запрещённый контракт отклоняется кодом. |
| Журнал | Исходник, контекст, снимок, отдельный файл каждого запроса, итог; тест перечитывает сохранённый JSON, проверяет provider/cost и отсутствие ключа. |
| Сквозные проверки | 15 тестов 03 с настоящими LangChain/SDK и контролируемым HTTP; общий прогон — 43 теста, OK; strict mypy — 14 файлов, ошибок нет. |
| Реальная модель | 2026-11-08: обе роли ответили через OpenRouter на `openai/gpt-4.1-mini`. Схемы и модели подтверждены, провайдеры записаны. Итог `approved_for_checks`, расход двух запросов $0.0010792. |

Согласно разрешённому исключению agent-stack используется совместимая
LangChain-интеграция: у текущего ChatOpenRouter воспроизведена потеря provider
в SDK; причина, версии и тест описаны в
[integration evidence](../../../docs/agents/openrouter-compatibility.md).
Все 46 разрешённых транзитивных версий зафиксированы в lock и совпадают
с установленным окружением; `pip check` ошибок не выявил.

Живая проверка закрыла последний критерий приёмки 03. Модели возвращают только предложение для будущих
программных проверок; брокер, денежный риск, источники и recovery следующих
тикетов не реализованы в 03. Имеющиеся чужие изменения 02 сохранены отдельно.
