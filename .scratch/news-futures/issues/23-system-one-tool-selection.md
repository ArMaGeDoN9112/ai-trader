# Выбирать функцию чтения через System One

Status: ready-for-agent

В мультиагентном маршруте Jev выбирает `get_company_news`, `get_market_context`
или переход к анализу. Аргументы берутся из задания. В трассе видны выбор и
модель. При недопустимом ответе функции чтения не вызываются.

## Приёмка

- Jev выбирает обе функции, а аналитик получает результаты и формирует предложение.
- Неизвестное имя останавливает обработку до обращения к брокеру.
- После прерывания на критике выбор инструмента не повторяется.
