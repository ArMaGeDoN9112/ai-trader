# 15. Разложить приложение и тесты по подсистемам

Status: resolved

Сгруппировать Python-пакет по назначению модулей. Держать встроенные настройки
и статические файлы рядом с подсистемами, которые их используют. Разнести
проверку торговых предложений, исполнение и подключение к Т-Банку по отдельным
модулям. Сгруппировать тесты и выделить общие тестовые имитации.

Оператор продолжает запускать прежние команды с существующим профилем и
каталогом данных. Контрольные точки должны загружаться с прежними именами
классов. Штатный сквозной прогон проверяет вход, защиту, восстановление и выход.
Тикет 01 запускается без сторонних библиотек. React относится к отдельной задаче.

## Результат

Подсистемы и размещение тестов описаны в [карте проекта](../../../README.md#структура-проекта).
Прошли 158 тестов, включая Chrome, восстановление контрольной точки со старыми
именами модулей и чтение профилей со старыми путями встроенных настроек.
Строгая проверка mypy прошла. Торговые интеграции в тестах подменены.
