# 05: Jev привязывает публикацию к компаниям

**What to build:** Публикация проходит через маршрутизатор с Jev и получает сохранённые привязки к нескольким компаниям каталога либо пустой результат. Аналитик может отличить прямые связи от гипотез косвенного влияния и проверить неопределённые результаты.

**Blocked by:** 03 — Аналитик и критик работают через OpenRouter; 04 — Проверяемое подключение к песочнице и каталогу инструментов.

**Status:** resolved

- [x] Jev вызывается через предусмотренный для структурированных решений интерфейс OpenRouter; его контракт не подменяется текстовым API сменой model ID.
- [x] Релевантность нескольким компаниям оценивается независимо: выбор одного варианта не выдаётся за полный список затронутых компаний.
- [x] Результаты используют идентификаторы выбранного каталога. Неизвестные компании и инструменты не создаются из неподтверждённого ответа модели.
- [x] Сохраняются прямая, косвенная или неуверенная связь, её оценка и ссылки на исходные данные. Связь сама по себе не становится торговым предложением.
- [x] Косвенное влияние через отрасль, сырьё или регулирование остаётся гипотезой; его проверка и объяснение передаются аналитику.
- [x] При недостатке оснований допустим пустой список. Ошибка или недоступность Jev отличается от подтверждённого отсутствия релевантных компаний.
- [x] Привязки могут охватывать весь выбранный каталог компаний; исполнение по-прежнему ограничено отдельно разрешёнными фьючерсами.
- [x] Смена версии Jev применяется с нового цикла, фактическая модель и доступные расходы сохраняются.
- [x] Проверки включают одну и несколько компаний, отсутствие связей, косвенное влияние, неопределённость, неизвестный идентификатор и сбой сервиса.
- [x] На примерах русскоязычных публикаций сохраняется проверяемый результат оценки качества; соответствие схеме не объявляется доказательством истинности связи.

## Answer

Предусловия 03 и 04 проверены по закрытой живой приёмке. Команда
`route` использует OpenRouter Decisions, сохраняет результат и журнал
по партиям. Косвенную и неуверенную привязку можно передать в существующий
контекст аналитика. [Запуск и проверка](../../../docs/jev.md).

## Review

- Standards. Входы маршрутизации переданы через типизированное состояние
  графа. Адаптер проверяет ответы и сопоставляет их с каталогом по той же
  таблице ключей, которую использовал при построении запроса.
- Spec. Аналитик отклоняет привязку от другой редакции, неоднозначное
  распределение сохраняется для проверки, доступные метаданные и расходы
  записываются даже при неверном формате ответов.
