# 06: Повторы и обновления правильно меняют новостной контекст

**What to build:** Новая публикация сопоставляется с сохранёнными новостными событиями и пополняет контексты компаний. Простая перепечатка не создаёт новый торговый сигнал, а новые факты, исправления, опровержения и независимые подтверждения доходят до повторного анализа.

**Blocked by:** 05 — Jev привязывает публикацию к компаниям.

**Status:** resolved

- [x] Модель отдельно оценивает совпадение события и наличие существенных новых сведений; общая тема не считается достаточным совпадением.
- [x] Оператор может увидеть исходные публикации, их источники, связи с событием и основания решения о повторе или обновлении.
- [x] Повторная публикация сохраняется, но сама по себе не запускает повторный торговый анализ и не обновляет возраст исходного основания для входа.
- [x] Обновление события, включая существенную редакцию или опровержение, сохраняет предысторию и инициирует анализ затронутых компаний.
- [x] Разные каналы, перепечатавшие один первоисточник, не считаются независимыми подтверждениями автоматически.
- [x] При неуверенном совпадении сохраняется спорная связь, анализ не подавляется и окончательное объединение не навязывается.
- [x] Ошибочное сопоставление можно исправить без удаления первичных публикаций и уже записанной истории решений.
- [x] Отсутствие события среди подобранных кандидатов не выдаётся за доказанную новизну; ограничения подбора и неопределённость остаются видимыми.
- [x] Проверки покрывают перефразированную перепечатку, одинаковую тему разных событий, новые факты, исправление числа, опровержение, независимое подтверждение и неоднозначное совпадение.

## Answer

После закрытия 05 команда `event-match` принимает результат `route`,
сопоставляет публикацию с кандидатами и сохраняет редакцию, решение и
запросы для компаний одной транзакцией SQLite. Просмотр доступен в `events`,
а `event-correct` записывает версию решения с причиной исправления.
Обработка запросов аналитиком описана в тикете 07.
[Запуск, форматы и ограничения подбора](../../../docs/events.md).
