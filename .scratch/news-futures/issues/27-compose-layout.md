# Фронтенд и бэкенд в Docker Compose

Status: resolved

Разместить React и Nginx в `frontend/`, Python API, воркер и тесты — в `backend/`.
Compose публикует только фронтенд на loopback. API проверяет Host, сессию и Origin
для команд. Воркер под управлением API стартует по команде оператора; его полномочия
по отношению к источникам и брокеру не меняются. Сохранять рабочие файлы в `.local`,
авторизацию Telegram — в отдельном томе.

Критерии: сборка двух образов, загрузка панели и защищённых API через один адрес,
сохранение локального состояния после остановки, штатные офлайн-проверки.
Команды запуска и диагностики: [руководство](../../../docs/runtime.md).

На отдельном профиле без ключей проверены загрузка панели, отклонение чужого Host
и Origin и сохранение паузы после перезапуска API. Прошли 190 тестов, включая Chrome.
