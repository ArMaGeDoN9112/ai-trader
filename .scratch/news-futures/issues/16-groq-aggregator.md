# 16. Переключать чат-модели между OpenRouter и Groq

Status: resolved

В настройках панели оператор выбирает агрегатор для сопоставления событий,
аналитика и критика. Привязка к компаниям использует типизированные решения
OpenRouter. У каждого агрегатора свой набор чат-моделей.

- Сохранённый выбор применяется со следующей редакции. Возобновлённая редакция
  использует зафиксированные настройки.
- Groq вызывается через Chat Completions со строгой JSON Schema. Отказ или
  некорректный ответ обрабатывается существующими проверками графа.
- Панель показывает сохранённый агрегатор и агрегатор последней редакции.

## Answer

Штатный граф проверен на подменённом HTTP-транспорте. Chromium проверяет
сохранение выбора и отображение применённого агрегатора. Прошли 171 тест,
проверка типов и сборка панели. Живой вызов Groq требует локального API-ключа.
