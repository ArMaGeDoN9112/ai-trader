# 07: Аналитик принимает решение с учётом компании и позиции

**What to build:** Поступившее обновление получает торговое предложение на основе накопленного контекста компании, текущего рынка, счёта и причины входа. Аналитик сравнивает разрешённых кандидатов и учитывает уже открытую позицию; критик проверяет основания и выбор.

**Blocked by:** 06 — Повторы и обновления правильно меняют новостной контекст.

**Status:** resolved

- [x] В анализ входят новая публикация, связанные новости с проверяемыми ссылками, текущий рынок, состояние счёта и сохранённая причина входа в открытую позицию.
- [x] Косвенные и неуверенные привязки проверяются по исходным данным; непроверенная гипотеза не выдаётся за установленное влияние.
- [x] Если контекст ограничен размером входа модели, пропуски обозначаются явно, исходные публикации остаются доступны, а основание действующей позиции не теряется молча.
- [x] При свободном счёте допустимы long, short и пропуск; при открытой позиции — удержание или полное закрытие.
- [x] Из нескольких затронутых компаний выбирается не более одного предложения по разрешённому инструменту с обоснованием; критик проверяет этот выбор и используемые сведения.
- [x] Предложение входа содержит обоснованные уровни входа, SL и TP; количество контрактов не устанавливается агентом в обход программного расчёта.
- [x] Закрытие текущей позиции обосновывается относящимися к ней сведениями. Новость по другому инструменту не вызывает автоматическую ротацию.
- [x] Изначальная причина входа сохраняется отдельно от последующих оценок и не переписывается задним числом для оправдания удержания.
- [x] При открытой позиции доступны удержание и полное закрытие. Увеличение, намеренное частичное закрытие и разворот отклоняются.
- [x] Проверяемые сценарии покрывают выбор из нескольких кандидатов, пропуск, удержание, опровержение причины входа и новость по другому инструменту.

## Answer

`analyze-event` обрабатывает действующий запрос из архива 06 вместе со
снимком рынка и счёта. `entry-reason` сохраняет исходное основание по
идентификатору позиции. Один цикл LangGraph сравнивает кандидатов,
проверяет цитаты и сохраняет выводы аналитика и критика.
[Запуск, форматы и журнал решения](../../../docs/company-decisions.md).
