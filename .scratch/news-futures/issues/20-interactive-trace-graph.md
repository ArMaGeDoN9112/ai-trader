# Интерактивный граф трассы решения

Status: ready-for-agent

Оператор открывает трассу публикации и выбирает узел, чтобы увидеть все сохранённые вызовы роли или инструмента. Узлы показывают фактически участвовавшие роли, повторные вызовы и последнюю сохранённую стадию. Записанные передачи задач и запросы инструментов имеют отдельное обозначение. Остальные стрелки отражают порядок записей.

Панель использует ответ `/api/trace` с существующей фильтрацией данных. Граф доступен только для чтения. По каждому вызову видны сохранённые вход, ответ, время и статус. Полная хронология остаётся доступной ниже.

Проверить переход из журнала в трассу, историю повторного вызова аналитика, передачу критику, вызов инструмента, выбор с клавиатуры и сохранение выбранного узла при обновлении. На узком экране прокручивается область графа.
