# 01: Контрольная публикация проходит всю цепочку локально

**What to build:** Оператор запускает воспроизводимый локальный сценарий: одна контрольная публикация сохраняется, получает привязку к компании, проходит аналитика и критика и заканчивается записанным результатом имитации исполнения. Это узкая сквозная основа следующих задач; внешние источники, модели и брокер в этом сценарии явно имитируются.

**Blocked by:** Нет (можно начинать сразу).

**Status:** ready-for-agent

- [x] Сценарий запускается из чистого окружения по документированной инструкции и выдаёт однозначный проверяемый результат.
- [x] Сохраняются исходная публикация, её источник, ссылка, устойчивый идентификатор, время публикации и получения.
- [x] Контрольный каталог различает компанию, её акцию и фьючерсный контракт; публикация привязана к известной компании.
- [x] Видна последовательность трёх ролей: маршрутизатор, аналитик компании и критик. Фиксированные тестовые ответы явно обозначены как имитация.
- [x] Торговое предложение отделено от исполнителя; контрольный результат проходит через независимую программную проверку.
- [x] Результат имитации, причина входа и связи с исходной публикацией сохраняются и доступны для просмотра после завершения процесса.
- [x] Сценарий не требует ключей, не вызывает платные API и не отправляет торговые поручения.
- [x] Автоматическая сквозная проверка воспроизводит сценарий и подтверждает отсутствие внешних торговых вызовов.

## Answer

Реализовано 2026-11-06, только срез 01. Язык — Python 3.11+, по выбору
пользователя; решение записано в `AGENTS.md`. Запуск и тесты используют только
стандартную библиотеку. Инструкция: [README.md](../../../README.md).

| Критерий | Проверяемое свидетельство |
| --- | --- |
| Чистое окружение и результат | `python -m news_futures run <новый каталог>`; сквозной процесс `-I -S`, результат `simulated_filled`, повторение даёт ту же трассу. |
| Исходная публикация | `publication.json` сохраняется до ролей; сквозной тест сравнивает все поля с контрольными значениями. |
| Компания, акция, фьючерс | Каталог в `trace.json`; проверяются разные ID, связи и экспирация. |
| Три роли | `roles` содержит `router → company_analyst → critic`, входы и фиксированные ответы с `mode: simulation`. |
| Независимая проверка | `execution.py`: исполнитель вызывает программную проверку; некорректные предложения отклоняются даже при согласии критика. |
| Сохранённый результат | `show` в новом процессе читает результат, причину входа и ссылки на публикацию/предложение/контракт с диска. |
| Без ключей и API | В реализации нет сетевого транспорта, ключей и клиентов; сквозной тест работает без переменных с ключами. |
| Отсутствие внешних вызовов | Audit hook блокирует socket/subprocess/shell; четыре отдельные пробы подтверждают запрет, а весь сценарий проходит под ним. |

Проверки: `python -m unittest discover -s tests -v` — 7 тестов, OK;
`python -m mypy --strict news_futures tests` — 7 файлов, ошибок нет
(mypy — только инструмент разработки). Ручные `run` и `show` с `-S` также
подтвердили `simulated_filled`; запуск без пути создаёт новый каталог автоматически.
Задачи 02–13, денежный риск и реальная защита не реализованы.
