# Обрабатывать необязательные цитаты при пропуске сделки

Status: ready-for-agent

Для `skip` с неподтверждённым влиянием передавать критику только проверяемые
цитаты. Сохранить сырой ответ для трассы. Для подтверждённого влияния и
торговых действий сохранить строгую проверку и показать конкретную причину
отклонения цитаты.
