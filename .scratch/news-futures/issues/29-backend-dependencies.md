# Единый список зависимостей бэкенда

Status: resolved

Использовать `requirements.txt` для Docker и `requirements-dev.txt` для локальной разработки. Свести прежние закреплённые версии в `constraints.txt`. Устанавливать SDK для теста регрессии OpenRouter и клиент Chrome DevTools только с зависимостями разработки, если они не нужны приложению транзитивно.

Приёмка включает сборку образа, проверку зависимостей и офлайн-прогон приложения и тестов.
