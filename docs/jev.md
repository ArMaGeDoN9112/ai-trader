# Привязки публикации через Jev

Команда `route` принимает сохранённую публикацию и отчёт
`diagnostics.json` от `sandbox-diagnostics`. В публикации нужны поля
`id`, `url` и `text`. Подходит объект `publication` из нужной редакции
в выводе команды `publications`. Выберите редакцию с доступным текстом.
В отчёте требуется доступная операция `operations.catalog` с данными
компаний. Из нескольких акций с одним `company_id` получается один вопрос
с известными именами и тикерами компании.

Используйте окружение с [зависимостями OpenRouter](openrouter.md) и ключ
`openrouter.api_key` в локальном `.local/credentials.toml`.

```powershell
.venv\Scripts\python -m news_futures route .local/route-05 --publication .local/publication.json --catalog .local/sandbox-report/diagnostics.json
.venv\Scripts\python -m news_futures show .local/route-05
```

Jev получает исходный текст и имена и тикеры компаний партиями до 40
компаний. Каждая компания оценивается своим вопросом Choice в
[OpenRouter Decisions API](https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request).
По умолчанию используется `typesafe/jev-1.14`. Чтобы сменить версию,
передайте `--config` с отдельным JSON-файлом и полем `model`, например
`typesafe/jev-1.13`. Версия фиксируется до следующего запуска.
Запросы тарифицируются OpenRouter.

В новом каталоге запуска сохраняются исходник, снимки каталога и настроек,
распределения оценок по партиям и итоговый `trace.json`. В нём указаны
запрошенная и фактическая версии, расходы из ответов сервиса и ссылки на
исходник и каталог. `completed` с `links: []` означает, что по всем
компаниям победил вариант отсутствия связи с вероятностью от 0,50.
При ошибке будет `failed`
с `links: null`, даже если часть каталога успела обработаться.
`CredentialsError` означает, что нужно проверить локальный ключ.

У привязки `score` равен единице минус вероятность отсутствия связи.
Если вероятность выбранного типа ниже 0,60, привязка помечается
`uncertain`. Так же помечается результат, если `none` выиграл,
но за все варианты связи вместе набралось больше 0,50.
Косвенная привязка указывает возможный механизм
(`industry`, `commodity` или `regulation`). Для ручной передачи
аналитику поместите выбранную привязку в `company_link` контекста
`analyze --context` вместе с исходной редакцией публикации целиком.
Хэш редакции `publication_revision_sha256` проверяется при передаче.
У ранних локальных трасс есть только хэш исходного файла, поэтому
для проверки редакции сформируйте привязку заново. Аналитик проверяет
косвенные и неуверенные связи и объясняет механизм по исходным данным.

## Проверка на русском тексте

```powershell
.venv\Scripts\python -m unittest discover -s tests -p test_jev.py -v
.venv\Scripts\python -m tests.jev_quality .local/jev-quality
```

Вторая команда делает семь платных запросов на синтетических примерах.
Ручные метки, ответы и число совпадений сохраняются в `evaluation.json`.
Дополнительные гипотезы считаются расхождениями с ручной разметкой.
Оценка относится к этому набору и пригодна для проверки ошибок модели.
