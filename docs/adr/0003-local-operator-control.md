# Локальная панель передаёт команды обработчику

Status: accepted

Панель остаётся доступной после остановки или сбоя обработчика, а закрытие вкладки оставляет обработку запущенной. Для этого жизненный цикл обработчика и подтверждение команд принадлежат локальному приложению, а браузер хранит состояние представления. Ручной запрос на закрытие проходит через тот же программный исполнитель и сверку, что и новостной выход, с [границей полномочий ADR 0001](0001-separate-proposals-from-execution.md).
