# LangGraph и LangChain для рабочих агентных сценариев

По требованию пользователя рабочие агентные сценарии строятся на LangGraph StateGraph, LangChain и Pydantic вместо отдельного самописного рантайма оркестрации и моделей. Это добавляет зависимости, но даёт общий механизм состояния, условных переходов, структурированных ответов и контрольных точек; конкретные интеграции и границы описаны в [agent-stack](../agents/agent-stack.md). Завершённый автономный контрольный сценарий тикета 01 сохраняется без сторонних библиотек, а исполнение заявок остаётся за независимым программным контуром согласно ADR 0001.
