# News-futures

Приложение анализирует новости Telegram и сохраняет проверяемые решения по фьючерсам. React-панель — в [frontend/](frontend/), Python API и обработчик — в [backend/](backend/).

**[Основное руководство](docs/runtime.md)** — единый актуальный документ: запуск Docker и Windows, настройки, архитектура, полномочия агентов и исполнителя, хранение данных, обновление и откат, диагностика и проверки.

Перед запуском существующей установки выполни нужные [миграции](docs/runtime.md#обновление-структуры-python-пакета). Панель: [127.0.0.1:8765](http://127.0.0.1:8765/); обработчик запускается отдельно из панели.
