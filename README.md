# Локальная цепочка news-futures/01

Проект написан на Python по выбору пользователя. Этот срез — воспроизводимая
**имитация**, а не торговая система: источник, компания, акция, фьючерс, ответы
маршрутизатора, аналитика и критика, цена исполнения и часы сценария фиксированы.
Контрольные данные находятся в `news_futures/control.json`. Ссылка на
`example.invalid` служит идентификатором оригинала и не открывается.

## Запуск из чистого окружения

Нужен только Python 3.11 или новее. Сторонних библиотек, ключей и сетевого
подключения для сценария и тестов не требуется. Выполняйте команды из корня
репозитория:

```console
python -m news_futures run .local/control-01
python -m news_futures show .local/control-01
```

В Windows можно заменить `python` на `py -3.11`, если интерпретатор установлен
через Python Launcher. Если команда указывает на неработающий псевдоним Microsoft
Store, используйте путь к установленному `python.exe`.

Первая команда возвращает JSON с `mode: "simulation"`,
`status: "simulated_filled"` и абсолютными путями к результатам. Вторая команда
читает трассу с диска после завершения первого процесса. Контрольный результат:
один условный контракт `control-future-2026-12`, long, цена 300.

Каталог запуска должен быть новым: существующий каталог не перезаписывается.
Чтобы получить новый каталог автоматически, выполните `python -m news_futures run`
и используйте путь `directory` из ответа для `show`.

## Что сохраняется

- `publication.json`: исходный текст, источник, внешний и составной устойчивый
  идентификаторы, ссылка, время публикации и получения. Записывается до ролей.
- `trace.json`: публикация, каталог с отдельными компанией, акцией и фьючерсом
  с экспирацией; последовательность ролей с входами и фиксированными ответами;
  программная проверка и результат исполнения с причиной входа и ссылками на
  предложение, компанию, контракт и публикацию.

Время `clock` и обе временные отметки публикации относятся к фиксированным часам
имитации, а не к фактическому времени запуска. Поэтому повторение в новом каталоге
даёт одинаковую трассу. Все роли и исполнение помечены `simulation`.

Исполнитель сам вызывает независимую проверку: проверяет связи публикации и
каталога, разрешённый контрольный контракт, согласие критика на идентификатор
предложения, одну условную единицу, сторону long, положительные целые цены,
порядок SL < вход < TP и непустую причину входа. При отказе результат — `rejected`,
без условного исполнения. Ответ критика не может отключить программную проверку.

Это проверка контрольного примера. Расчёт объёма и денежного риска, сроки
актуальности, сверка счёта и нативная защита относятся к следующим задачам.
Здесь нет транспорта, клиентов API, загрузки секретов и отправки поручений.
Если процесс прерван, исходная публикация остаётся; незавершённый запуск
не считается успешным без `trace.json`. Для повторения используйте новый каталог.

## Проверки

```console
python -m unittest discover -s tests -v
```

Сквозной тест запускает команду в отдельном изолированном Python-процессе (`-I -S`,
без сторонних site-packages),
убирает переменные с ключами и через audit hook запрещает создание сокетов,
сетевые операции и запуск внешних программ. Отдельные пробы подтверждают,
что запрет работает для сокета, HTTP, подпроцесса и shell. Затем другой процесс
читает и проверяет сохранённую трассу. Также проверяются воспроизводимость,
защита от перезаписи и отказы независимого исполнителя.

Для разработки и проверки типов (только этот шаг загружает инструмент из PyPI):

```console
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m mypy --strict news_futures tests
```

На Linux/macOS используйте `.venv/bin/python`. Каталог `.local`, виртуальное
окружение и кэши исключены из Git. Последующие срезы описаны ниже;
контрольный сценарий остаётся независимым от их зависимостей.
